## 💻 Projects (주요 개발 경험)
데이터 파이프라인 구축 및 ML 모델링 핵심 프로젝트입니다.

**[Data Engineering/ML] HALO: 시공간 위험도 예측 기반 안전 보행 내비게이션 (2026) - 🏆 해커톤 대상**
* **내용:** 5종의 이질적 공공 데이터를 19.5만 개의 도로 세그먼트로 병합하고, 타겟 누수를 방지한 시계열 위험도 예측 모델(AUC 0.94) 구축 및 라우팅 UI 구현.
* **기술 스택:** Python, GeoPandas, SQL, scikit-learn

**[Healthcare AI/XAI] C.O.R.E CDSS: AI 기반 응급실 환자 중증도 예측 시스템 (2026) - 🎓 캡스톤 프로젝트**
* **내용:** 환자의 임상 데이터를 기반으로 중증도를 4단계로 자동 분류(Classification)하고, SHAP을 활용하여 AI의 판단 근거를 시각화하는 의사결정 지원 시스템 및 대시보드 개발.
* **기술 스택:** Python, ML Classification, SHAP (Explainable AI), Web UI

**[Data Analysis] 정신질환 환자 의료비 부담 및 치료 특성 분석 (2025) - 🏆 심평원 공모전 수상**
* **내용:** 건강보험공단 진료 데이터를 활용하여 정신질환 환자의 치료 특성(재방문율, 질환 연관성 분석 등)을 통계적으로 파악하고, 실효성 있는 보건의료 정책(Win-Win wellness 등) 제안.
* **기술 스택:** Python, Data Analysis, Association Rule Learning
